# LazyBot

Discord-бот, который поддерживает **один свободный временный голосовой канал** в выбранной категории. Постоянные комнаты можно исключать из управления. Дополнительный модуль считает приглашения, отправляет приветствия и ведёт статистику входов и выходов.

Код хранится в публичном репозитории [alexander-kozakoff/LazyBot](https://github.com/alexander-kozakoff/LazyBot). Рабочая копия размещена в Botkeep. Для проекта создано отдельное приложение Discord **LazyBot**, существующее приложение **LAZYbot** не используется.

Инструкция нового модуля: **[приглашения, приветствия и статистика](docs/COMMUNITY.md)**. По умолчанию он выключен: сначала подготовьте разрешения Discord, затем задайте `COMMUNITY_ENABLED=true`.

Ссылки для владельца: [настройки нового бота](https://discord.com/developers/applications/1565018164020912238/bot), [пригласить LazyBot на сервер](https://discord.com/oauth2/authorize?client_id=1565018164020912238&scope=bot&permissions=1024&integration_type=0). Ссылка-приглашение запрашивает только просмотр каналов; управление каналами настраивается отдельно в нужной категории.

## Текущая настройка

LazyBot работает на сервере **Lazy Dice** в категории **«Голосовые каналы»**. ID категории хранится локально в `.env`. Для управления временными комнатами боту нужны просмотр, управление каналами и «Подключаться» в этой категории; серверное право администратора не требуется.

**«Лобби»** настроено как постоянная комната: для роли **LazyBot** в её правах явно запрещено **«Управлять каналом»**. Бот не учитывает её при подсчёте свободных комнат и не удаляет.

Для постоянной переписки используется существующий канал **`#чат`**. В инструкции настройки с нуля название категории «Голосовые комнаты» приведено как пример; текущая рабочая категория — **«Голосовые каналы»**.

## Как устроены комнаты и чаты

- В выбранной категории бот создаёт `Комната 1`, `Комната 2` и далее. При создании выбирает минимальный свободный номер среди управляемых комнат. Существующие комнаты не переименовывает.
- Когда заняли последнюю свободную временную комнату, создаётся ещё одна.
- Когда пустых временных комнат несколько, остаётся пустая с наименьшим номером. Остальные удаляются после **5 секунд непрерывной пустоты**. Отсчёт начинается при получении события выхода; выполнение удаления в Discord дополнительно занимает время. Вход человека или другого бота отменяет отсчёт для этой комнаты.
- При старте и после восстановления связи бот заново проверяет категорию. Дополнительно сверяется каждые 30 секунд. Сразу после события и во время задержки пустых комнат может быть несколько.
- По умолчанию обычные голосовые каналы выбранной категории считаются временными, включая созданные вручную. AFK-канал, сцены и текстовые каналы исключены из обработки.
- Для постоянной голосовой комнаты явно запретите роли **LazyBot** право **«Управлять каналом»** в настройках этой комнаты. Бот полностью исключит её из подсчёта и удаления. Даже если постоянная комната пуста, бот поддерживает отдельную свободную временную комнату.
- Удаление голосовой комнаты удаляет её встроенный текстовый чат. Архива нет. Чат оставшейся пустой комнаты сохраняется до удаления комнаты.
- Для важных сообщений используйте постоянный текстовый канал **`#общение` вне автоматической категории**. Если подходящий уже есть, используйте его. Бот не создаёт текстовые каналы автоматически.
- Бот не подключается к голосовой связи, не слушает звук и не читает сообщения.

При работе через Botkeep ваш компьютер может быть выключен. При локальном запуске бот работает, пока компьютер включён и программа запущена. Уже созданные каналы остаются на сервере после остановки. Запускайте только **один экземпляр** LazyBot: перед локальной проверкой остановите облачную копию.

### Как сделать комнату постоянной

1. В Discord нажмите правой кнопкой на нужный голосовой канал → **Настроить канал → Права доступа**.
2. Добавьте или выберите роль **LazyBot**.
3. Для **«Управлять каналом»** выберите красный крестик — **«Запретить»**. Остальные права можно оставить как есть.
4. Сохраните изменения. Работающий бот получает обновление прав через события Discord.

Метка постоянной комнаты — явный запрет для роли LazyBot в правах **отдельного канала**. Удаление роли из списка прав или запрет только «Подключаться» такую метку не устанавливают. В самой категории управление каналами должно оставаться разрешённым.

Чтобы вернуть комнату под управление бота, замените запрет «Управлять каналом» на **«Унаследовать»** или **«Разрешить»**. Проверьте также права просмотра и подключения. После этого комната снова участвует в подсчёте и может быть удалена как лишняя пустая.

## 1. Открыть проект в WebStorm

1. Запустите WebStorm → **File → Open** (или **Open** на стартовом экране).
2. Выберите папку `E:\AI\LazyBot`.
3. Код находится в папке `src`. Основной запуск — `src/index.js`.

Нужен Node.js **24.17 или новее**. Для этого компьютера подготовлен отдельный `E:\AI\LazyBot\.runtime\node.exe`, версия 24.22.1. Он не меняет системный Node.js и не отправляется в GitHub. На другом компьютере установите актуальный совместимый Node.js LTS с [официального сайта](https://nodejs.org/en/download).

В **Settings → Languages & Frameworks → Node.js** выберите этот `node.exe` как **Node interpreter**. Если нужно указать **Package manager**, выберите `E:\AI\LazyBot\.runtime\node_modules\npm`.

Если WebStorm предлагает конфигурацию Node.js: файл JavaScript — `src/index.js`, рабочая папка — `E:\AI\LazyBot`, интерпретатор — указанный выше. После настройки используйте зелёную кнопку запуска. Сам бот читает `.env`, вручную копировать токен в настройки запуска не нужно.

## 2. Создать приложение Discord и получить токен

1. Войдите в свой аккаунт на [Discord Developer Portal](https://discord.com/developers/applications).
2. Нажмите **New Application**, задайте имя **LazyBot**, создайте приложение.
3. Откройте **Bot**. Если бот ещё не создан, используйте **Add Bot**. Для получения ключа нажмите **Reset Token**.
4. Скопируйте токен **только в локальный файл `.env`**, в значение `DISCORD_TOKEN`.
5. Для режима только голосовых комнат специальные переключатели не нужны. Для приглашений и приветствий включите **Server Members Intent**, прежде чем задавать `COMMUNITY_ENABLED=true`. **Presence Intent** и **Message Content Intent** не требуются.

Пароли, токен и коды входа не отправляйте в переписку, GitHub или скриншоты. Если токен случайно стал публичным, сбросьте его через **Reset Token** и замените локальное значение.

## 3. Добавить LazyBot на сервер

Вы должны быть владельцем сервера или иметь необходимые права управления.

1. В приложении Discord Developer Portal откройте **Installation**.
2. Выберите **Guild Install**. В **Default Install Settings** используйте scopes **bot** и **applications.commands** для поддержки команд `/`.
3. Начните с права **View Channels**. Не выдавайте **Administrator** и серверное **Manage Channels**: управление разрешим только в нужной категории на следующем шаге.
4. Скопируйте **Install Link**, откройте его, выберите свой сервер и подтвердите добавление.
5. Если интерфейс предлагает **OAuth2 → URL Generator**, выберите scope **bot**, право **View Channels** и используйте полученную ссылку. Это альтернативный способ приглашения.

Бот может отображаться офлайн до первого успешного запуска — это нормально.

## 4. Подготовить отдельную категорию

1. В Discord выберите категорию голосовых каналов или создайте новую, например **«Голосовые комнаты»**. Нужные постоянные комнаты отметьте исключениями до первого запуска бота по инструкции выше.
2. Откройте **Настройки категории → Права доступа**, добавьте роль **LazyBot**.
3. Для LazyBot разрешите **Просматривать каналы**, **Управлять каналами** и **Подключаться** в этой категории. Остальные серверные права не меняйте. Discord требует право «Подключаться» для удаления голосовых каналов, даже если бот сам не присоединяется к разговору. Особенно это важно в приватных категориях. [Описание неявных ограничений Discord](https://github.com/discord/discord-api-docs/blob/main/developers/topics/permissions.mdx#implicit-permissions).
4. Для участников проверьте права **Просматривать каналы**, **Подключаться**, **Говорить**. Для временного встроенного чата нужны **Отправлять сообщения** и **Читать историю сообщений**.
5. Если временных комнат ещё нет, первую бот создаст сам. Для постоянной переписки используйте существующий текстовый канал или создайте `#общение` вне автоматической категории.

Новые комнаты наследуют права категории. Права временных комнат можно синхронизировать с категорией. В постоянных комнатах сохраняйте отдельный запрет «Управлять каналом» для LazyBot: синхронизация уберёт эту метку.

## 5. Заполнить три значения в .env

В Discord откройте **Настройки пользователя → Расширенные → Режим разработчика**. Это позволяет копировать ID через контекстное меню.

1. Правой кнопкой по значку сервера → **Копировать ID сервера**. Вставьте в `DISCORD_GUILD_ID`.
2. Правой кнопкой по выбранной категории → **Копировать ID категории**. Вставьте в `DISCORD_CATEGORY_ID`. Нужен ID категории, а не комнаты.
3. В `DISCORD_TOKEN` должен быть токен со страницы **Bot**.

Если `.env` отсутствует, скопируйте `.env.example` в `.env` или выполните команду `npm run setup`. Эта команда не перезаписывает существующие настройки. На подготовленном компьютере файл уже создан.

Формат:

```dotenv
DISCORD_TOKEN=ваш_секретный_токен
DISCORD_GUILD_ID=числовой_ID_сервера
DISCORD_CATEGORY_ID=числовой_ID_категории
```

После изменений `.env` перезапустите бота. Не переносите токен в исходный код. `.env` исключён из Git ещё до первого коммита.

## 6. Запустить и проверить

Самый простой запуск в Windows — двойной щелчок по **`Start-LazyBot.cmd`**. Окно программы должно оставаться открытым. Для остановки используйте **Ctrl+C** в этом окне или кнопку **Stop** в WebStorm.

В WebStorm после выбора нужного Node.js можно запускать задачу **start** из `package.json`.

Для терминала на этом компьютере:

```powershell
$env:Path = "$PWD\.runtime;$env:Path"
.\.runtime\npm.cmd start
```

Первая строка выбирает локальный Node.js 24 для этой сессии терминала. Без неё npm может запустить старый системный Node.js. Системные настройки не изменяются.

Для нового компьютера с подходящим системным Node.js:

```powershell
npm ci
npm run setup
npm start
```

Проверка на сервере:

1. После подключения появляется `Комната 1`.
2. Зайдите в неё: появляется свободная `Комната 2`.
3. Напишите тестовое сообщение во встроенном чате `Комната 2`, не размещая ничего важного.
4. Выйдите из `Комната 1`: через 5 секунд бот оставит её и удалит лишнюю `Комната 2` вместе с тестовым чатом.
5. Повторите вход и выход; попробуйте вернуться за 5 секунд — занятую комнату бот не должен удалять.
6. Проверьте с другом переходы и одновременные подключения. В устойчивом состоянии остаётся одна свободная комната.
7. Перезапустите программу. Существующие занятые комнаты сохраняются, число свободных восстанавливается.
8. Убедитесь, что постоянное «Лобби» внутри рабочей категории сохраняется и не заменяет свободную временную комнату. Каналы вне рабочей категории также должны остаться на месте.

Discord обрабатывает изменения по сети: между событием, последней проверкой и удалением существует короткое сетевое окно. Избегайте ручного изменения категории во время массового перемещения участников.

## GitHub

Репозиторий `alexander-kozakoff/LazyBot` публичный. В нём хранятся код, инструкция, образец настроек и `package-lock.json`. Папки `.runtime`, `node_modules`, `data`, настройки WebStorm, журналы, базы SQLite и файл `.env` исключены из Git.

Изменения сохраняем в WebStorm через **Commit and Push**. Перед публикацией проверьте список файлов: токен и накопленная статистика остаются вне репозитория.

## Работа через Botkeep

Используется обычный бесплатный сервер: профиль Node.js 24, совместимый с требованием проекта **24.17+**, команда запуска **npm start**, зависимости из `package-lock.json`. Фактическую версию Node.js можно проверить по консоли среды.

- Настройки хранятся во вкладке **Environment / Среда**. Токен вводится как секрет. Файл `.env` из GitHub не загружается.
- Для запуска: **Overview → Start**, для остановки — **Stop**, сообщения — **Console**.
- Обновление: локальные изменения → `npm run verify` → ваш **Commit and Push** → в Botkeep **GitHub → Check repository → Merge files → Sync repository** → дождаться нового коммита и времени синхронизации → **Start**.
- Перед обновлением скачайте свежую резервную копию базы. **Merge files** сохраняет дополнительные файлы, а **Replace files** может удалить `data/` со статистикой и настройками.
- Включение приглашений и приветствий, проверка после перезапуска и резервные копии описаны в [отдельной инструкции](docs/COMMUNITY.md).
- Проверка переноса: остановите локальную копию, проверьте вход и выход из голосовой комнаты, сохранность «Лобби», перезапуск в панели и работу после выключения ПК.

Не нажимайте повторную синхронизацию, пока первая выполняется. Если импорт завис на **Preparing source files** и блокирует Files, проверьте GitHub-вкладку. При отсутствии отмены обратитесь в Support с ID сервера; секреты в обращение не включайте.

Бесплатный хостинг находится в бета-версии, непрерывная работа не означает гарантию доступности. Если на сервере не запускается новая версия, остановите облачную копию до временного локального запуска.

## Проверки для разработки

На подготовленном компьютере:

```powershell
$env:Path = "$PWD\.runtime;$env:Path"
.\.runtime\npm.cmd run verify
```

На компьютере с подходящим системным Node.js:

```powershell
npm run verify
```

Проверки не подключаются к Discord и не создают и не удаляют настоящие каналы. Они проверяют голосовые комнаты, права, атрибуцию приглашений, повторные события, команды, сохранение SQLite и восстановление резервной копии. Реальное подключение проверяется отдельно после заполнения `.env`.

## Если что-то не работает

| Сообщение или ситуация | Что проверить |
| --- | --- |
| Не заполнен `DISCORD_TOKEN` | Вставьте токен локально в `.env`, сохраните файл и перезапустите |
| Сервер недоступен | Правильный ID сервера; LazyBot добавлен именно на этот сервер |
| Категория не найдена | Вставлен ID категории, а не канала; категория существует |
| Недостаточно прав / Нет доступа | Для роли LazyBot в категории и временных комнатах разрешены просмотр, управление каналами и «Подключаться» |
| Различаются права комнат | Проверьте права временных комнат; при необходимости синхронизируйте их с категорией. В постоянных комнатах сохраните отдельный запрет управления для LazyBot |
| Постоянная комната учитывается как временная | В правах именно этой комнаты выбрана роль LazyBot и явно запрещено «Управлять каналом» |
| Достигнут лимит каналов | Освободите место в категории или на сервере; занятые комнаты бот ради этого не удаляет |
| Бот офлайн | В Botkeep процесс запущен и в Console нет ошибки; при локальном запуске компьютер включён. Токен действителен |
| Ошибка privileged intents / 4014 | Для `COMMUNITY_ENABLED=true` нужен Server Members Intent в Developer Portal; либо временно задайте `false` |
| Нет команд сообщества | Включён COMMUNITY_ENABLED; бот перезапущен; установка поддерживает applications.commands; проверьте Console |
| /setup сообщает, что учёт недоступен | Для роли бота нужно серверное право «Управлять сервером», а также видимость каналов приглашений |
| База не открывается | Node.js 24.17+, путь COMMUNITY_DATABASE_PATH, свободное место и права записи; см. Console |
| Два окна LazyBot | Остановите лишний экземпляр, оставьте один |

После ошибок бот делает повторные попытки не чаще раза в 30 секунд. Если проблема устранена, работа восстановится. Если изменили `.env`, нужен перезапуск.

## Структура

- `src/index.js` — подключение к Discord и обработка событий.
- `src/room-manager.js` — правило одной свободной комнаты и таймеры.
- `src/discord-adapter.js` — проверки прав, создание и удаление комнат.
- `src/config.js` — чтение настроек и значения по умолчанию.
- `src/logger.js` — понятные сообщения без вывода исходных запросов и токенов.
- `src/community.js` — события участников, уведомления, команды и резервные копии.
- `src/invite-tracker.js` — очередь и определение источника входа.
- `src/community-store.js` — статистика и настройки SQLite.
- `src/community-commands.js` — команды Discord и права администратора.
- `src/community-messages.js` — шаблоны и ограничение уведомлений.
- `data/` — создаваемые при включении модуля база и резервные копии; не входят в Git.
- `test/` — автоматические проверки.
- `scripts/` — подготовка настроек и проверка синтаксиса.

Официальные справки: [Discord Developer Portal](https://discord.com/developers/applications), [чаты голосовых каналов](https://support.discord.com/hc/en-us/articles/4412085582359-Text-Channels-Text-Chat-In-Voice-Channels), [discord.js](https://discord.js.org/docs/packages/discord.js/stable).
